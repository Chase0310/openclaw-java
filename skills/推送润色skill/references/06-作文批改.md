# 作文批改（全年级）选项池

> 下钻深度：2-3层
> 数据来源：数据规格§2 作文批改

---

## L0 推送摘要

**该说：** 作文标题、综合得分
**不该说：** 不说各维度评分、不说改进建议

**示例输出：**
> "小雨写了一篇《我喜爱的大榕树》，我看了以后给打了85分，写得不错～"

---

## L1 选项池

| 优先级 | 选项文案 | 触发条件 | 数据字段依赖 | 绑定场景ID |
|--------|---------|---------|------------|-----------|
| 1 | 写得好的地方有哪些？ | 有好句/亮点数据 | 好句摘录 / 亮点摘要 | A |
| 2 | 哪些方面需要改进？ | 有改进点数据 | 改进摘要 / 最低维度 | A |
| 3 | 各项评分怎么样？ | 有6维评分数据 | 评分维度 | A |
| 4 | 怎么帮他提高写作？ | 始终可用 | — | E |

---

## L2 下钻

### L1-1：写得好的地方有哪些？

**回复要点：** 好句数量 + 亮点摘要

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 还有哪些需要改进？ | → 复用 L1-2 逻辑 → E | A |
| 怎么保持这个优势？ | → 场景E | E |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-2：哪些方面需要改进？

**回复要点：** 最弱维度名称 + 改进点摘要
**不该说：** 不说改进方法

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| {最弱维度}怎么提高？ | → 场景E | E |
| 具体哪里写得不好？ | → 展开诊断 → L3: "{问题}怎么改进？" → E | A |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-3：各项评分怎么样？

**回复要点：** 6维评分展开，指出最强和最弱维度

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| {最弱维度}怎么提高？ | → 场景E | E |
| 为什么{维度}扣分多？ | → 展开原因 → L3: "怎么改进？" → E | A |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-4：怎么帮他提高写作？

**直达 → 场景E**

---

## 完整路径图

```
L0 推送 → L1(4个选项，取TOP3)
             │
             ├─ L1-1 好的地方   → L2: 需要改进的？ → 复用L1-2 →【E】
             │                    L2: 怎么保持？ → 【E】
             │
             ├─ L1-2 需改进     → L2: {维度}怎么提高？ → 【E】
             │                    L2: 具体哪里不好？ → L3 → 【E】
             │
             ├─ L1-3 各项评分   → L2: {维度}怎么提高？ → 【E】
             │                    L2: 为什么扣分多？ → L3 → 【E】
             │
             └─ L1-4 怎么提高写作 → 直达【E】
```
