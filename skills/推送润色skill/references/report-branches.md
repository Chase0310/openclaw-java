## 1. 数学一对一辅学营

**该说：** 课次名称、时长、做题量、新掌握考点数、"有X个需要巩固"
**不该说：** 不说具体是哪几个知识点需要巩固

**按优先级说：**
1. 课次名称
2. 学习时长（"大概X分钟"）
3. 总做题量
4. 新掌握考点数（正面信息）
5. 薄弱点数（>0时"还有X个需要再巩固一下"，不说具体哪些）

**额外规则：**
- 薄弱点=0 → "全部掌握了，表现很棒"
- 有奖杯能力标签（可能为空）→ 有就末尾简短提一句
- 不提"母题""知识树""基础层/中等层/高阶层"

**字段：** 课次名称、学习时长_分钟、总做题量（汇总.总做题量）、新掌握考点数、查出薄弱点数、奖杯能力标签（数组，可能空）

**示例：**
- 时长40，做题35，新掌握14，薄弱2 → "{childName}今天学了加减乘除法，大概40分钟做了35道题。新掌握了14个考点，还有2个需要再巩固一下。"
- 时长25，做题20，新掌握12，薄弱0，奖杯有 → "{childName}今天学了数轴分类讨论，25分钟做了20道题，12个考点全部掌握了！表现很棒～"

## 2. 语文/英语一对一

**该说：** 课程名称、通关X/Y个
**不该说：** 不说哪些没通关、不说优势/提升空间的具体内容

**按优先级说：**
1. 课程名称
2. 通关情况（完成了X/Y个）
3. 未全部通关时 → "还有X个需要巩固"

**额外规则：**
- 自生长更新（非首次推送）→ 体现"又/新完成了"的增量感
- PT学习记录型（只做题没上课）→ 不提课堂表现
- 全部通关 → 强调正面
- 不提"PT""精准学""能力标签"，用"知识点"或"考点训练"
- 不融入优势/提升空间的AI话术

**字段：** 课程名称、学科、报告形态（标准课堂型/PT学习记录型）、是否首次上此lesson、通关PT数/该lesson总PT数

**示例：**
- 首次，语文，通关5/8 → "{childName}今天学了《大青树下的小学》，完成了5个知识点，还有3个需要巩固一下。"
- 非首次（之前3个），通关5/8 → "{childName}在《大青树下的小学》又通关了2个知识点，现在5/8都完成了，进步不错～"
- 全通关 → "{childName}今天学了Unit 5，8个知识点全部通关了，表现很棒～"

## 3. 高中全科一对一

**该说：** 学科、时长、答题量、"新掌握了X个知识点"
**不该说：** 不说具体哪些知识点

**按优先级说：**
1. 学科
2. 学习时长
3. 答题量
4. 新增掌握知识点数
5. 有薄弱时 → "还有一些需要关注的地方"

**额外规则：**
- 正确率<60% → 不直接报正确率
- 正确率≥80% → 可以提正确率
- 不提"气泡图""难度等级"

**字段：** 学科、总学习时长_分钟、答题量、正确率、新增掌握知识点数、未掌握知识点数

**示例：**
- 数学，21min，35题，正确率0.405，新掌握8，未掌握20 → "{childName}今天学了数学，大概20分钟做了35道题，新掌握了8个知识点，还有一些需要关注的地方。"
- 物理，30min，20题，正确率0.85，新掌握5，未掌握0 → "{childName}今天学了物理，30分钟做了20道题，正确率85%，5个知识点全部掌握了～"

## 4. 作业批改

**该说：** 对了X道错了Y道
**不该说：** 不说错因方向、不说能力维度

**按优先级说：**
1. 批改了多少题
2. 答对/答错
3. 有错题 → "有X道需要关注一下"
4. 全对 → 强调正面

**额外规则：**
- 不报正确率百分比，用"答对了X道"
- 不提"雷达图""8维能力""考点分布"

**字段：** 批改数、答对、答错

**示例：**
- 8题，对6错2 → "{childName}今天的作业批改了8道题，答对了6道，有2道需要关注一下。"
- 8题全对 → "{childName}今天的作业全做对了，8道题一道没错，表现很棒！"

---

## 5. 作文批改

**该说：** 作文标题、综合得分
**不该说：** 不说各维度评分、不说改进建议

**字段：** 作文标题、综合得分

**示例：**
- 标题=我喜爱的大榕树，85分 → "{childName}写了一篇《我喜爱的大榕树》，我看了以后给打了85分，写得不错～"
- 标题=春天来了，68分 → "{childName}写了一篇《春天来了》，我看了以后给打了68分，有些地方可以更好，您可以看看～"

---

## 6. 计算训练

**该说：** 练习内容、答对/总题数、正确率
**不该说：** 不说进步趋势具体数值

**字段：** 练习标题、答对题数/总题数、正确率

**≤80字**

**示例：**
- 标题=20以内退位减法，对12/总16，75% → "{childName}今天练了20以内的退位减法，16道题做对了12道，正确率75%。"
- 全对 → "{childName}今天口算练习全对了，20道题一道没错，计算越来越稳了～"

## 7. 看图写话

**该说：** 作文标题、段落数
**不该说：** 不评价质量

**≤50字**

**字段：** 作文标题、学生创作段落数

**示例：**
- 标题=撑起一片绿荫，3段 → "{childName}今天完成了一篇看图写话《撑起一片绿荫》，写了3段，您可以看看～"

## 8. 作文辅导

**该说：** 作文标题
**不该说：** 不评价质量

**≤60字** 体现"在我的辅导下"的价值。

**字段：** 作文标题、学生创作段落数

**示例：**
- 标题=撑起一片绿荫 → "{childName}在我的辅导下完成了一篇作文《撑起一片绿荫》，您可以看看～"

## 9. 周报（含阶段进步检测）

**该说：** 学习天数、跨周对比（天数增减）、有进步时提progressSummary
**不该说：** 不说具体哪些科目进步/退步、不说错题情况、不说各科数据

**按hasProgress分支：**

### hasProgress=true
1. 周报出来了
2. 本周学习天数（比上周多/少就说）
3. 融入progressSummary（已是一句话，自然融入即可）
4. 一句模糊总评

### hasProgress=false
1. 周报出来了
2. 本周学习天数
3. 模糊总评

### 无上周数据（首份周报）
1. 第一份周报出来了
2. 本周学习天数
3. 不提跨周对比

**字段：** 学习天数、上周学习天数、总时长_分钟、上周总时长_分钟(null=无)、hasProgress、progressSummary(null=无)、寒雪评语（仅用于判断基调）

**示例：**
- 5天，上周4天，hasProgress=true，progressSummary="有2科排名提升了" → "{childName}这周的学习周报出来了。这周学了5天比上周多了1天，而且有2科的排名都提升了，进步挺明显的～"
- 7天，上周7天，hasProgress=false → "{childName}这周的周报来了。连续学了7天，整体学得不错～"
- 3天，首份周报 → "{childName}的第一份周报出来了。这周学了3天，我跟您说说情况～"

## 10. 数学学情日报（3-9年级+高中）

**该说：** 今日学习时长、做题量、新掌握题型数、突破中题型数
**不该说：** 不说具体哪些题型、不提"PT""Z值"，用"题型"代替

**额外规则：**
- 消息末尾固定带"（截止今晚10点）"
- 新掌握>0 → 优先提正面信息
- 突破中>0但新掌握=0 → "正在攻克X个题型"
- 全部掌握 → "今天的题型都掌握了，表现很棒"
- 正确率≥80% → 可提一句
- 不说"一对一""精准学"等应用名，统一说"数学"

**字段：** 今日做题量、今日学习时长_分钟、今日正确率、新掌握PT数、突破中PT数

**示例：**
- 时长95，做题28，新掌握2，突破中3 → "{childName}今天数学学了大概95分钟，做了28道题。新掌握了2个题型，还有3个正在突破中。（截止今晚10点）"
- 时长40，做题15，正确率0.93，新掌握3，突破中0 → "{childName}今天数学学了大概40分钟，做了15道题，3个题型都掌握了，正确率也挺高的，表现很棒～（截止今晚10点）"
