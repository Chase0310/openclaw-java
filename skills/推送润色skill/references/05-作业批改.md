# 作业批改（全年级）选项池

> 下钻深度：2层
> 数据来源：数据规格§2 作业批改

---

## L0 推送摘要

**该说：** 对了X道错了Y道
**不该说：** 不说错因分类、不说能力维度

**示例输出：**
> "浩浩今天的作业批改了8道题，答对了6道，有2道需要关注一下。"

---

## L1 选项池

| 优先级 | 选项文案 | 触发条件 | 数据字段依赖 | 绑定场景ID |
|--------|---------|---------|------------|-----------|
| 1 | 错题集中在什么类型？ | 有错因分析数据 | 错因分析数组 | A |
| 2 | 哪些能力比较薄弱？ | 有8维能力评分数据 | 能力维度评分 | A |
| 3 | 做得好的地方有哪些？ | 有高分维度 | 能力维度评分 | A |
| 4 | 怎么帮他改进？ | 始终可用 | — | E |

---

## L2 下钻

### L1-1：错题集中在什么类型？

**回复要点：** 错因TOP3 + 各自占比，不逐题列举
**不该说：** 不说怎么练

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 这类错题怎么练？ | → 场景E | E |
| 具体哪道题错了？ | → 场景B → B出口 → E | B |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-2：哪些能力比较薄弱？

**回复要点：** 8维能力中的薄弱维度 + 关联知识点
**不该说：** 不说怎么提升

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 怎么提升这个能力？ | → 场景E | E |
| 为什么这个能力薄弱？ | → 场景B → B出口 → E | B |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-3：做得好的地方有哪些？

**回复要点：** 高分维度的正面评价

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 还有哪些需要加强的？ | → 复用 L1-2 逻辑 → E | A |
| 接下来该重点练什么？ | → 场景E | E |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-4：怎么帮他改进？

**直达 → 场景E**

## 完整路径图

```
L0 推送 → L1(4个选项，取TOP3)
             │
             ├─ L1-1 错题类型   → L2: 怎么练？ → 【E】
             │                    L2: 具体哪道错？ → 【B】→【E】
             │
             ├─ L1-2 薄弱能力   → L2: 怎么提升？ → 【E】
             │                    L2: 为什么薄弱？ → 【B】→【E】
             │
             ├─ L1-3 做得好的   → L2: 需要加强的？ → 复用L1-2 →【E】
             │                    L2: 重点练什么？ → 【E】
             │
             └─ L1-4 怎么改进    → 直达【E】
```
