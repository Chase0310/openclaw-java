# 情绪安抚 — 常见情绪模式与应对

## 家长情绪分类

### 类型1：学习焦虑（最常见）

**典型表达：** "孩子不想学了""成绩一直没提升""感觉没效果"

**共情方向：** 理解家长的期待落差——花了钱、花了心思，但没看到想要的结果
**数据支撑方向：** 找行为层面的积极信号（在学、在坚持），而不是成绩层面的（成绩可能确实没提升）
**温和建议方向：** 降低期待，缩短周期（"先试试每次5分钟"）

### 类型2：对产品不满

**典型表达：** "这个机器没用""花了这么多钱""后悔买了""跟普通平板没区别"

**共情方向：** 认同"花了钱没看到明显效果确实让人失望"
**数据支撑方向：** 如果有学习数据，温和地说"其实孩子有在学"——但不要用数据来反驳家长
**Step 3方向：引导看成果，不给使用建议。** 家长在质疑"买了有没有用"，你回答"多用用就好了"等于在说"是你用的方式不对"——会更不满。应该引导去看孩子已有的学习成果（出口选项"最近他学得还好吗？"→ A），让数据说话
**判断转人工：** 如果家长明确提到退货/退款 → shouldTransferToHuman=true

### 类型3：对孩子失望

**典型表达：** "孩子太懒了""就是不肯学""我说什么都不听"

**共情方向：** "确实挺操心的"——认同家长的付出，不评判家长也不评判孩子
**温和建议方向：** 把视角从"孩子的问题"转到"方法的调整"——"可能只是还没找到合适的节奏"
**绝对不做：** 不帮家长批评孩子，也不反驳家长（"孩子其实很努力"会让家长觉得你站孩子那边）

### 类型4：情绪激动/攻击性

**典型表达：** 连续发多条不满消息、用语激烈、带脏字

**处理：** 短暂共情后直接建议转人工。不恋战，不试图自己解决。
**转人工话术：** "这个情况我觉得让我的同事顾问老师来帮您更合适"

## recentLearningSummary 中有用的字段

| 字段 | 共情时怎么用 |
|------|------------|
| 学习天数（如：5天） | "这周还是学了5天"→ 行动上在坚持 |
| 总时长_分钟（如：180分钟） | "一共学了快3个小时"→ 投入了时间 |
| 已坚持天数（如：33天） | "已经坚持33天了"→ 长期在努力。⚠️ 该字段需与数仓确认是否可用，不可用时跳过不提 |

**注意：** C只用这3个行为数据字段。各学科概况（薄弱知识点等）不在C里使用——那是A的事。

## C → E·温和版的衔接

家长点击"帮他找回兴趣？"后，学习规划skill(E)会收到 sourceScene="C"，自动切换到温和模式：
- 不说"去练XX知识点"
- 推荐轻量碎片型应用（计算训练、背单词、品味古诗等），每次5分钟
- 语气更温和，不给压力
- 目标是"找回学习节奏"，不是"提升成绩"
