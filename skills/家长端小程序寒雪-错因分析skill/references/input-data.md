# 错因分析 — 输入数据字段说明

## 通用字段（所有学科共享）

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| subject | string | currentReportContext.subject | "数学"/"语文"/"英语" |
| questionContent | string/null | 数仓查询：按knowledgePoint+reportId定位 | 题目原文。部分报告无题目数据时为null |
| studentAnswer | string/null | 同上 | 学生的答案 |
| correctAnswer | string/null | 同上 | 正确答案/标准答案 |
| childName | string | 用户基础信息 | 孩子姓名，用于回复中称呼 |
| childGrade | string | 用户基础信息 | 年级，用于判断学段 |
| conversationHistory | array | 服务端存储 | 最近10轮对话原文，用于理解上下文 |
| todaySessionSummary | object | 程序维护 | 今日会话摘要，用于判断是否已分析过同一道题 |

## 语文/英语专属字段

| 字段 | 类型 | 说明 |
|------|------|------|
| negativeAbilityTag | string/null | 负向能力标签。如"判断文章表达效果的稳定性有待提升"。数学为null |
| negativeTagAIText | string/null | 标签的自然语言包装版。如"在判断文章表达效果方面还需要多加练习"。数学为null |

## 数据完整性的三种情况

| 情况 | questionContent | studentAnswer | correctAnswer | 处理方式 |
|------|----------------|---------------|---------------|---------|
| 完整信息 | 有 | 有 | 有 | 完整错因分析（Step 2） |
| 部分缺失 | 有题目但无答案，或有答案无题目 | — | — | 按可用信息尽量分析，缺失部分不猜 |
| 仅有对错 | null | null | null | 事实兜底（Step 3） |

## 能力标签覆盖范围

**只有1-9年级的语文和英语有能力标签（negativeAbilityTag + negativeTagAIText），其他全部为null。**

| 学段 | 学科 | 能力标签 |
|------|------|---------|
| 1-2年级 | 语文、英语 | ✅ 有 |
| 3-9年级 | 语文、英语 | ✅ 有 |
| 3-9年级 | 数学 | ❌ 无 |
| 高中 | 全部9科（数语英物化生政史地） | ❌ 全部无 |

## 不同报告类型的数据差异

| 报告类型 | 覆盖学科 | 题目内容来源 | 有无能力标签 | 特殊说明 |
|---------|---------|------------|-----------|---------|
| 语文/英语一对一（1-2年级） | 语文、英语 | PT失败尝试中的错题 | 有 | 标签已有AI话术包装版 |
| 数学一对一辅学营（3-9年级） | 数学 | 母题列表中的题目 | 无 | 有所属层级（基础/中等/高阶） |
| 语文/英语一对一（3-9年级） | 语文、英语 | PT失败尝试中的错题 | 有 | 标签已有AI话术包装版 |
| 高中全科一对一 | 数语英物化生政史地 | 知识点列表中的题目 | 全部无 | 有难度等级和所属章节 |
| 作业批改 | 综合 | 批改结果中的错题 | 有（8维能力标签） | 标签维度更多 |
| 数学学情日报 | 数学 | 错题列表（跨App汇总） | 无 | 有来源App字段 |
