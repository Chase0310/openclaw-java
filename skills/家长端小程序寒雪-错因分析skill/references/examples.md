# 错因分析 — 各学科输入输出示例

## 示例1：数学3-9年级（完整信息，无能力标签）

**输入：**
```json
{
  "subject": "数学",
  "childName": "小鉴",
  "childGrade": "7年级",
  "questionContent": "已知方程 x²-2kx+k+6=0 有两个不相等的实数根，求 k 的取值范围。",
  "studentAnswer": "k > 9/4",
  "correctAnswer": "k < -2 或 k > 3（即 Δ = 4k²-4(k+6) > 0）",
  "negativeAbilityTag": null,
  "negativeTagAIText": null
}
```

**期望输出：**
> "从答题情况来看，小鉴可能是在判别式的不等号方向上搞混了——求'有两个不相等的实数根'应该是Δ>0，他算出了Δ的表达式但最后解不等式的时候方向弄反了。说明公式是会的，就是条件判断还不太熟练。"

**分析要点：** 对比学生答案"k>9/4"和正确答案"k<-2或k>3"，发现学生可能算对了Δ的表达式但解二次不等式时出错。不给学习建议。

## 示例4：高中数学（完整信息，知识点+正确率体系）

**输入：**
```json
{
  "subject": "数学",
  "childName": "安安",
  "childGrade": "高一",
  "questionContent": "已知集合A={x|x²-5x+6≤0}，集合B={x|x>a}，若A⊆B，求实数a的取值范围。",
  "studentAnswer": "a < 2",
  "correctAnswer": "a ≤ 2",
  "negativeAbilityTag": null,
  "negativeTagAIText": null
}
```

**期望输出：**
> "从答题情况来看，安安可能是在处理'子集'关系的边界条件时漏了等号——A⊆B要求A的所有元素都在B里，A的最小值是2，所以a需要≤2（取等号时2也在B中）。她写成了a<2，差了一个等号。整体思路是对的，就是边界条件需要再仔细一点。"

**分析要点：** 高中题目更注重逻辑严谨性，这里差的是一个等号的边界问题。

{
  "subject": "数学",
  "childName": "浩浩",
  "childGrade": "8年级",

  "studentAnswer": "AF:FC = 1:3",
  "correctAnswer": "AF:FC = 1:2",
  "negativeAbilityTag": "几何证明中辅助线的构造能力有待提升",

**分析要点：** 结合能力标签"辅助线构造能力"，但措辞转化为家长听得懂的语言。

## 示例7：高中物理（无能力标签）

**输入：**
```json
{
  "subject": "物理",
  "childName": "安安",
  "childGrade": "高一",
  "questionContent": "一个质量为2kg的物体放在粗糙水平面上，受到一个大小为10N、方向与水平面成30°角斜向上的拉力作用，物体沿水平面做匀速直线运动，求物体与水平面间的动摩擦因数μ。（g取10m/s²）",
  "studentAnswer": "μ = 0.5",
  "correctAnswer": "μ ≈ 0.58",
  "negativeAbilityTag": null,
  "negativeTagAIText": null
}
```

**期望输出：**
> "从答题情况来看，安安可能是在受力分析的时候漏了一个力——斜向上的拉力不只有水平分力，还有竖直向上的分力会减小地面对物体的支持力。如果只用重力算正压力，摩擦因数就会算小了。力的分解这块还需要再仔细一点。"

**分析要点：** 高中物理常见错误是受力分析不完整，这里把专业术语（正压力、分力）转化为家长能理解的表达。

```json

  "studentAnswer": "D",
  "correctAnswer": "B（辛亥革命结束的是封建君主专制制度，不是封建制度）",
  "negativeAbilityTag": null,
  "negativeTagAIText": null
}
```

**期望输出：**
> "从答题情况来看，安安可能是把B选项当成正确的了——'封建制度'和'封建君主专制制度'看起来差不多，但其实是两个不同的概念。辛亥革命结束的是君主专制，不是整个封建制度。历史题里这种措辞上的细微差别确实很容易混淆。"
