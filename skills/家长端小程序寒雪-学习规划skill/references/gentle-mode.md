# E·温和版详细规则

## 触发条件

sourceScene = "C"（从情绪安抚skill过来）

## 温和版和正常版的区别

温和版的家长刚经历了情绪安抚——他们可能在说"孩子不想学""我很焦虑"。这时候如果你说"建议去一对一上课"，家长会觉得你在给压力。温和版的目标是帮孩子"找回学习节奏"，不是"提升成绩"。

| 维度 | 正常版 | 温和版 |
|------|--------|--------|
| 目标 | 提升/巩固 | 找回节奏 |
| 推荐应用 | 一对一上课、精准学做题 | 轻量碎片型（计算训练、背单词、品味古诗等） |
| 时间要求 | 按正常学习节奏 | 每次5分钟就好 |
| 语气 | 专业建议 | 温和、低压力 |
| 知识点 | 具体推荐 | 不推荐具体知识点 |

## 可推荐的轻量碎片型应用

| 应用 | 适用学科 | 特点 |
|------|---------|------|
| 计算训练 | 数学（1-6年级） | 口算，每次5分钟，有成就感 |
| 字词听写 | 语文 | 寒雪聊聊子功能，碎片化 |
| 单词听写 | 英语 | 寒雪聊聊子功能，碎片化 |
| 学练背单词 | 英语 | 寒雪聊聊子功能 |
| 品味古诗 | 语文 | 寒雪聊聊子功能，有趣味性 |
| 故事大王 | 语文 | 寒雪聊聊子功能，趣味性强 |
| 古诗文默写 | 语文 | 寒雪聊聊子功能 |

## 温和版回复示例

**低年级（1-2年级）：**
> "可以让{childName}先试试计算训练，每次5分钟就好，就当做个小游戏。等他慢慢找回感觉了，再慢慢加量就行，不用着急。"

**中高年级（3-9年级，数学薄弱）：**
> "不用一上来就安排太多，可以先让{childName}每天花5分钟做做计算训练找找手感，周末有空了再上一节课。慢慢来就好。"

**中高年级（语文/英语相关）：**
> "可以让{childName}先试试每天花5分钟背几个单词或者听听古诗，不用像上课那么正式，就当是放松时间里顺便学一点。"

**高中：**
> "高中确实压力大，可以让{childName}先从自己最擅长的科目入手，每天花一小段时间做几道题保持手感。不用急着补最弱的，先从有信心的开始。"

## 温和版的红线

- 不说"去练XX知识点" → 太有压力
- 不推荐系统上课（一对一） → 上课时间长，跟"轻量"矛盾
- 不说"成绩一定会提升" → 承诺效果
- 不列超过2个建议 → 说太多反而有压力
- 不给具体时间表 → "每天上课30分钟+练题20分钟"这种不说
