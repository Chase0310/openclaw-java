# 学习规划知识库（learningPlanKB）使用说明

## 知识库结构

learningPlanKB 由分发层根据当前学情状态检索后传入，结构为：

```json
{
  "matched_recommendations": [
    {
      "学情状态": "知识点没学懂",
      "推荐路径名": "上课→做题→订正",
      "推荐应用": ["数学一对一(辅学营)", "数学精准学", "错题本"],
      "话术模板": "建议先让{孩子名}在数学一对一里把{知识点}重新上一遍课...",
      "注意事项": ["3-9年级数学有精准学"]
    }
  ]
}
```

## 匹配优先级

当 matched_recommendations 有多条时，按以下优先级选取最合适的1-2条：

### 定向模式优先级

| 优先级 | 学情状态 | 推荐路径 |
|--------|---------|---------|
| 1 | 有未订正错题 | 先订正 → 再巩固 |
| 2 | 知识点没学懂（未掌握/薄弱） | 上课 → 做题 → 订正 |
| 3 | 学懂了但做题不熟练（可能掌握/不熟练） | 做题 → 订正 |
| 4 | 想提升特定能力 | 对应应用组合 |
| 5 | 全部掌握 | 续学/拓展 |

### 全局模式优先级

| 优先级 | 学情状态 | 推荐路径 |
|--------|---------|---------|
| 1 | 有未订正错题的学科 | 先推订正 |
| 2 | 有薄弱知识点的学科 | 按严重程度排序 |
| 3 | 练得少的学科 | 增加时间 |
| 4 | 各学科都不错 | 按计划继续 |

## 年级段应用可用性

推荐应用前必须检查当前年级段是否有该应用：

| 年级段 | 数学可用 | 语文可用 | 英语可用 | 其他 |
|--------|---------|---------|---------|------|
| 1-2年级 | 计算训练、看图列式（无精准学、无辅学营） | 语文一对一、看图写话 | 英语一对一 | 错题本 |
| 3-9年级 | 一对一辅学营、精准学、计算训练、错题本 | 语文一对一、作文辅导、作文批改 | 英语一对一、作文辅导、作文批改 | 错题本 |
| 高中 | 一对一（同步+提升）、精准学（仅同步打通）、错题本 | 一对一 | 一对一 | 物化生政史地一对一、精准学（物理/化学/生物有）、错题本 |

## 常见"推不了"的情况

| 情况 | 正确处理 |
|------|---------|
| 1-2年级家长问数学怎么提升 | 推荐计算训练，不推精准学（不存在） |
| 语文英语家长问"去精准学练" | 语文英语没有独立精准学，精准学功能融合在一对一中 |
| 高中提升课程知识点 | 不推精准学（提升课程不打通），推一对一继续学 |
| 高中物理/化学/生物 | 有精准学可推荐（同步课程打通）；政史地没有精准学 |
| 学科薄弱知识点为null | 只能推"继续在家教机上练"，不能推荐具体知识点 |
