# 周报（全年级）选项池

> 下钻深度：2-3层
> 数据来源：数据规格§2 周报
> 周报是按周聚合的跨学科数据，L1/L2涉及跨学科比较规则

---

## L0 推送摘要

**该说：** 学习天数、跨周对比（天数增减）、"整体不错"/"有几个地方值得关注"、hasProgress 信号检测（见下方L1触发条件）
**不该说：** 不说哪些科目进步/退步、不说错题具体情况、不说各科数据

**示例输出：**
> "天天这周的学习周报出来了。这周学了5天，比上周多了1天，整体学得不错～"

---

## L1 选项池

| 优先级 | 选项文案 | 触发条件 | 数据字段依赖 | 绑定场景ID |
|--------|---------|---------|------------|-----------|
| 1 | 这周哪些科目进步了？ | hasProgress=true（进步信号检测结果，见技术规格书§2.4） | 跨周相同知识点 / 本周vs上周行为指标 | A |
| 2 | 有哪些需要关注的地方？ | 有薄弱知识点 或 有未订正错题 | 各科薄弱数据 | A |
| 3 | 错题情况怎么样？ | 周错题 ≥1 | 错题_新增 | A |
| 4 | 跟上周对比怎么样？ | 有上周数据 | 上周学习天数 | A |
| 5 | 接下来怎么安排学习？ | 始终可用 | — | E |

> **注意：** 当 hasProgress=false 时，"这周哪些科目进步了？"**不出现**，其余选项按优先级顺位上移。

---

## L2 下钻

### L1-1：这周哪些科目进步了？

**回复要点：**
- 行为指标（天数/时长/做题量）跨周对比
- 同知识点跨周正确率对比（有就比）
- **不比各科整体正确率**（每周知识点不同）

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 怎么保持这个进步？ | → 场景E（学习规划·全局模式） | E |
| 还有哪些需要关注？ | → 复用 L1-2 逻辑 → E | A |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-2：有哪些需要关注的地方？

**回复要点：** 按学科分列本周薄弱点
**不该说：** 不说"比上周差了"

| L2 选项 | 去向 | 变量填充 | 绑定场景ID |
|---------|------|---------|-----------|
| {学科}的薄弱点怎么补？ | → 场景E | 取最薄弱学科名 | E |
| 为什么{知识点}还没学懂？ | → 场景B → B出口 → E | 取薄弱知识点名 | B |
| 好的 | → 收口（系统固定回复） | — | CLOSE |

### L1-3：错题情况怎么样？

**回复要点：** 新增{X}道 / 已订正{Y}道 / 订正率{Z}% / 科目分布

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 怎么帮他把错题订正？ | → 场景E | E |
| 为什么错题集中在{学科}？ | → 场景B → B出口 → E | B |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-4：跟上周对比怎么样？

**回复要点：** 按跨周对比规则回答

**跨周对比规则：**

| 能跨周比 | 不能跨周比 |
|---------|-----------|
| 学习天数、总时长、做题总量 | 各科正确率（每周知识点不同） |
| 错题新增/订正数/订正率 | 薄弱知识点数量 |
| 超过X%同年级 | 新掌握知识点数量 |
| 同知识点跨周正确率 | — |

| L2 选项 | 去向 | 绑定场景ID |
|---------|------|-----------|
| 退步的地方怎么补回来？ | → 场景E | E |
| 进步的地方怎么保持？ | → 场景E | E |
| 好的 | → 收口（系统固定回复） | CLOSE |

### L1-5：接下来怎么安排学习？

**直达 → 场景E（学习规划·全局模式）**

---

## 完整路径图

```
L0 推送 → L1(5个选项，取TOP3)
             │
             ├─ L1-1 哪科进步了  → L2: 怎么保持？ → 【E·全局】
             │                     L2: 需要关注的？ → 复用L1-2 →【E】
             │
             ├─ L1-2 需要关注的  → L2: {学科}怎么补？ → 【E】
             │                     L2: 为什么没学懂？ → 【B】→【E】
             │
             ├─ L1-3 错题情况    → L2: 怎么订正？ → 【E】
             │                     L2: 为什么集中在{科}？ → 【B】→【E】
             │
             ├─ L1-4 跟上周对比  → L2: 退步怎么补？ → 【E】
             │                     L2: 进步怎么保持？ → 【E】
             │
             └─ L1-5 接下来怎么安排 → 直达【E·全局】
```
