## 1. 数学一对一辅学营

**学段：** 3-9年级
**掌握体系：** 母题 + before/after掌握状态（熟练掌握/可能掌握/未掌握/未知）
**特有数据：** 奖杯能力标签（0-3个，可能为空）、所属层级（基础/中等/高阶）

| 家长问 | 回复要点 | 不说什么 |
|--------|---------|---------|
| "哪些知识点还需要练？" | 列出课后`未掌握`的母题："{考点名}做了{X}道对了{Y}道"。逐个列出 | 不说怎么练 |
| "错题是什么情况？" | 今天错了{X}道，主要集中在{考点名}方向。说分布不逐题展开 | 不逐题分析错因（那是错因分析skill的事） |
| "今天掌握了哪些新内容？" | 列出课前`未掌握/未知`→课后`熟练掌握`的母题 | 不说接下来学什么 |
| "跟上次比有进步吗？" | 课前vs课后对比：哪些从未掌握变成掌握了。无进步时不说"退步"，说"还在巩固中" | 不比不同知识点的正确率 |
| "接下来怎么学比较好？" | → 转学习规划skill(E) | 不自己回答 |

**"全部掌握"时的兜底：** 所有母题都是`熟练掌握`→ "这节课的内容都掌握得很好"，选项条里"接下来怎么学"兜底为"建议按计划继续下一节课"。

## 2. 语文/英语一对一

**学段：** 1年级-高三（含校内同步课+精品课）
**掌握体系：** PT通关体系（已通关/尝试未通过/未参与）+ 能力标签
**特有数据：** 优势项目_AI话术、提升空间_AI话术、学习环节列表、是否首次上此lesson
**重要特性：** 报告会随新PT通关自生长更新

| 家长问 | 回复要点 | 不说什么 |
|--------|---------|---------|
| "相关的知识点进度怎么样？" | 通关了{X}/{Y}个PT，列出已通关和未通关的名称 | 不说怎么学 |
| "哪些知识点还薄弱？" | 列出提升空间PT和尝试未通过PT的名称+尝试次数。结合能力标签（用自己的话融入，不直接复制AI话术原文） | 不说怎么提升 |
| "今天学了什么内容？" | 列出已完成的学习环节+PT情况（通关/尝试/未参与） | 不给评价好坏 |
| "跟上次比有进步吗？" | 同lesson内PT通关数对比。首次上课→兜底："这是{孩子名}第一次上这节课，后面再看看进步情况～" | 不做跨lesson对比 |
| "接下来怎么学比较好？" | → 转学习规划skill(E)。但先判断优先级：①PT学习记录型→建议先上课；②有未通关PT+未完成环节→建议先上课再做题；③全通关→建议下一节 | 转E时带上判断结果 |

**语文英语差异：** 数据结构完全一致，仅学科和内容不同。

## 3. 高中全科一对一

**学段：** 高中
**覆盖学科：** 数语英物化生政史地（9科）
**掌握体系：** 知识点+正确率（已掌握/不熟练/薄弱），无PT/母题/能力标签
**特有数据：** 难度等级、所属章节、明日学习建议

| 家长问 | 回复要点 | 不说什么 |
|--------|---------|---------|
| "哪些知识点还需要练？" | 按优先级排序：薄弱→不熟练→已掌握。列出知识点名+正确率+所属章节 | 不说怎么练 |
| "错题是什么情况？" | 正确率不足的知识点分布、做题量和正确率 | 不逐题分析错因 |
| "今天掌握了哪些新内容？" | 新增掌握的知识点名+所属章节 | 不说接下来学什么 |
| "跟上次比有进步吗？" | 近7天历史对比（如有）。无历史数据→"目前还没有对比数据" | 不比跨天不同知识点正确率 |
| "接下来怎么学比较好？" | → 转学习规划skill(E)。可引用reportData中的`明日学习建议`作为参考 | 不自己展开建议 |

| "错题集中在什么类型？" | 错因TOP3及占比 | 不逐题展开 |

## 7. 看图写话

**学段：** 1-2年级
**特殊规则：** 无评分维度。只做正面评价，绝对不能有任何负向评价。

| 家长问 | 回复要点 | 不说什么 |
|--------|---------|---------|
| "写了什么内容？" | 简述创作内容，正面评价 | — |
| "写得怎么样？" | 纯正面评价 | 绝对不说"需要改进""不够好" |
| "怎么让他写得更好？" | → 转学习规划skill(E·温和版) | 不自己回答 |

## 9. 周报

**特有数据：** progressSignals（进步检测结果，可能为null）
**跨周对比规则：** 学习天数/总时长/做题量/错题可以跨周比，各科正确率不能跨周比（每周知识点不同）

| 家长问 | 回复要点 | 不说什么 |
|--------|---------|---------|
| "这周哪些科目进步了？" | 根据progressSignals展开：天数增长说天数、排名提升说学科、答题量说数量。null时说"整体比较平稳" | 不说各科正确率对比 |
| "有哪些需要关注的地方？" | 按学科分列本周薄弱点 | 不说"比上周差了" |
| "错题情况怎么样？" | 新增{X}道/已订正{Y}道/订正率{Z}%/科目分布 | — |
| "跟上周对比怎么样？" | 能比的比（天数、时长、做题量、错题、同知识点正确率），不能比的不比（各科正确率、薄弱知识点数） | — |
| "接下来怎么安排学习？" | → 转学习规划skill(E) | 不自己回答 |

**hasProgress=false时：** "这周哪些科目进步了？"这个选项不出现。

## 10. 数学学情日报

**学段：** 3-9年级+高中（共用）
**掌握体系：** PT-Z（0/1/2/3）
**特有数据：** 今日做题量、今日学习时长、新掌握PT数、突破中PT数、PT列表、错题列表、重点关注知识点、今日数学课次报告列表
**术语替换：** 面向家长时"PT"说"题型"，"Z值"不提。"已掌握"="掌握了"，"突破中"="还在练"，"薄弱"="需要多练练"

| 家长问 | 回复要点 | 不说什么 |
|--------|---------|---------|
| "哪些题型还没掌握？" | 列出Z<3且今日做过题的PT："{题型名}做了{X}道对了{Y}道，目前还在练" | 不说怎么练 |
| "今天新掌握了什么？" | 列出当日Z升至3的PT名称，正面评价 | 不说接下来学什么 |
| "错题是什么情况？" | 今天数学一共错了{X}道，集中在{题型名}方向 | 不逐题分析（家长追问"为什么错"时转错因分析skill） |
| "想看具体哪节课的情况？" | → 转切换报告skill(D)，列出当天数学课次报告 | 不自己展开课次内容 |
| "接下来怎么学比较好？" | → 转学习规划skill(E) | 不自己回答 |

**3-9年级vs高中差异：** 数据来源App不同（辅学营vs高中一对一），课次报告关联类型不同。回复规则一致。
