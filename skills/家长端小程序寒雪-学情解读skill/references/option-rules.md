# 选项条规则

## 选项条基本机制

选项条挂在最新一条寒雪消息下方，家长点一条后整组消失，新回复挂新选项。

- 选项句式由产品定义（固定句式+动态变量），不是你自由生成的
- 每层按优先级排序，取TOP展示（通常2-5个）
- 已点过的选项不再出现
- 按自然日重置（次日0点恢复满）

## 选项栈机制

家长每点一条选项，剩下的存起来。当前路径走完后，把存的拿出来继续挂：

1. 家长点L1中的一条 → 剩余L1存入栈
2. 寒雪回复+挂L2选项
3. 家长点L2中的一条 → 剩余L2存入栈
4. 当前路径到达终点（学习规划/收口）→ 先挂栈中的L2剩余
5. L2全走完 → 弹出栈中的L1剩余
6. L1全走完 → 选项消失，进入自由输入

家长中途自由打字不影响选项栈，当前层级剩余选项保留。

## "好的"收口选项

所有L2/出口选项列表末尾，系统自动追加"好的"选项。这不是你生成的，是系统追加的。点击后系统直接返回固定文案"好的，有什么想问的随时找我～"，不调LLM。

## 各报告类型的L1选项池摘要

> 完整选项池见逐应用选项池文件夹。以下为触发条件摘要。

### 数学一对一辅学营（3-9年级）

| 选项 | 触发条件 |
|------|---------|
| "哪些知识点还需要练？" | 有课后`未掌握`的母题 |
| "错题是什么情况？" | 有课后`未掌握`或`可能掌握`的母题 |
| "今天掌握了哪些新内容？" | 有课前非掌握→课后掌握的母题 |
| "跟上次比有进步吗？" | 有课前vs课后对比数据 |
| "接下来怎么学比较好？" | 始终可用 |

### 语文/英语一对一

| 选项 | 触发条件 |
|------|---------|
| "相关的知识点进度怎么样？" | 有PT数据 |
| "哪些知识点还薄弱？" | 有提升空间PT或尝试未通过PT |
| "今天学了什么内容？" | 有学习环节或PT记录 |
| "跟上次比有进步吗？" | 非首次上此lesson |
| "接下来怎么学比较好？" | 始终可用 |

### 高中全科一对一

| 选项 | 触发条件 |
|------|---------|
| "哪些知识点还需要练？" | 有`薄弱`或`不熟练`知识点 |
| "错题是什么情况？" | 有正确率<100%的知识点 |
| "今天掌握了哪些新内容？" | 新增掌握知识点数>0 |
| "跟上次比有进步吗？" | 有近7天历史数据 |
| "接下来怎么学比较好？" | 始终可用 |

### 周报

| 选项 | 触发条件 |
|------|---------|
| "这周哪些科目进步了？" | hasProgress=true |
| "有哪些需要关注的地方？" | 有薄弱点/错题 |
| "错题情况怎么样？" | 周错题≥1 |
| "跟上周对比怎么样？" | 有上周数据 |
| "接下来怎么安排学习？" | 始终可用 |

### 数学学情日报

| 选项 | 触发条件 |
|------|---------|
| "哪些题型还没掌握？" | 有Z<3且今日做过题的PT |
| "今天新掌握了什么？" | 有当日Z升至3的PT |
| "错题是什么情况？" | 今日答错题目数≥1 |
| "想看具体哪节课的情况？" | 当日有≥1份数学课次报告 |
| "接下来怎么学比较好？" | 始终可用 |

### 作业批改/作文批改/计算训练/看图写话/作文辅导

选项池较短（2-3个），详见逐应用选项池对应文件。
