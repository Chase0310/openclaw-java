# 各报告类型数据结构概览

> 完整JSON字段定义见数据规格文档。本文件提供各报告类型的核心字段摘要，帮助快速理解数据结构差异。

## 数据结构速查

| 报告类型 | 掌握体系 | 核心数据字段 | 能力标签 |
|---------|---------|------------|---------|
| 数学一对一辅学营 | 母题before/after | 母题列表（考点名、课前/课后掌握状态、做题量、层级） | 奖杯标签（0-3个，可能为空） |
| 语文/英语一对一 | PT通关 | PT列表（PT名、通关状态、尝试次数、判定）、学习环节列表 | 正向/负向能力标签+AI话术（1-9年级有，高中无） |
| 高中全科一对一 | 知识点+正确率 | 知识点列表（名称、难度、掌握状态、做题量、正确率、章节） | 无 |
| 作业批改 | 8维能力 | 各维度得分、错题分类、总分 | 8维能力标签 |
| 作文批改 | 6维评分 | 各维度评分、好句数、亮点摘要 | 无 |
| 计算训练 | 正确率趋势 | 题目数、正确率、平均用时、趋势 | 无 |
| 看图写话 | 无评分 | 创作内容摘要 | 无 |
| 作文辅导 | 无评分 | 创作内容摘要 | 无 |
| 周报 | 聚合 | 各科时长、做题量、错题统计、寒雪评语、progressSignals | 无 |
| 数学学情日报 | PT-Z | PT列表（PT名、Z值、掌握状态、今日做题数）、错题列表、重点关注知识点 | 无 |

## 掌握状态枚举值

| 报告类型 | 枚举值 |
|---------|--------|
| 数学一对一辅学营 | 熟练掌握 / 可能掌握 / 未掌握 / 未知 |
| 语文/英语一对一 | 已通关(优势) / 已通关(提升空间) / 尝试未通过 / 未参与 |
| 高中全科一对一 | 已掌握 / 不熟练 / 薄弱 |
| 数学学情日报 | 已掌握(Z=3) / 突破中(0<Z<3) / 薄弱(Z=0) |

## "进步"的判断依据（按报告类型不同）

| 报告类型 | "进步"的定义 |
|---------|------------|
| 数学一对一辅学营 | 课前`未掌握/未知`→课后`熟练掌握`的母题存在 |
| 语文/英语一对一 | 同lesson内PT通关数增长（不做跨lesson对比） |
| 高中全科一对一 | 近7天内未掌握→掌握（不比跨天不同知识点正确率） |
| 计算训练 | 正确率趋势有增长 |
| 首次上课（所有类型） | 无进步数据→兜底话术 |
| 周报 | 5个信号（学习天数/总时长/订正率/排名/答题量）检测 |
