# 切换报告 — 定位失败的各级兜底

## 兜底决策树

```
extractedParams有日期+学科？
├→ 有 → 查数仓
│   ├→ 命中1份 → 直接切换
│   ├→ 命中多份 → 列出让家长选
│   ├→ 匹配不到 → "那天没有{学科}记录" + 推今日列表
│   └→ 超出7天 → "记得不太清楚了" + 跳转报告中心（可反向唤起寒雪）
├→ 部分有（只有学科没有日期，或只有日期没有学科）
│   └→ 走Level 2模糊意图 → 推今日列表
└→ 都没有（"想看报告"）
    └→ 走Level 2模糊意图 → 推今日列表
        ├→ 家长选了一份 → 切换
        └→ 家长选"没有想看的" → Level 3跳转报告中心
            └→ 报告中心可反向唤起寒雪
```

## 各兜底级别的回复模板

### 匹配不到（有日期+学科但查不到）

> "那天好像没有{学科}的学习记录呢。您想看看今天的报告吗？"
> + 今日报告列表（最近5份）+ "没有想看的"

### 超出7天

> "之前的我记得不太清楚了，不过您可以在报告中心里找到，找到以后点'跟我聊聊'我就能帮您看了～"
> + 跳转报告中心入口（jumpToReportList=true）
> 家长在报告中心找到报告后，通过"跟寒雪聊聊这个报告"按钮反向唤起寒雪，此时Agent会加载该报告数据正常解读

### 今日无报告

> "今天还没有学习记录呢。之前的报告都在报告中心里，您可以去看看～"
> + "没有想看的"（跳转报告中心）

### 完全没有报告（新用户）

> "目前还没有{childName}的学习报告呢，让他在家教机上上一节课，上完我就来跟您汇报～"
> 不附任何入口和选项条

## 同一天同学科多份报告的处理

这种情况在数学场景中比较常见（上午一节课、下午一节课）。

回复模板：
> "那天{childName}上了两节数学课——一个是上午10点的一元二次方程，一个是下午3点的数列。您想看哪个？"

选项条：
```
- 10:00 一元二次方程
- 15:00 数列
- 没有想看的
```

## 从日报进入D时的列表范围

日报选项条"想看具体哪节课的情况？"触发D时，列表范围限定为**当天的数学课次报告**：
- 3-9年级：数学一对一辅学营报告
- 高中：高中数学一对一报告（仅同步课程，提升课程不纳入日报体系）

不列其他学科的报告，不列精准学/错题本（它们没有独立课次报告）。
