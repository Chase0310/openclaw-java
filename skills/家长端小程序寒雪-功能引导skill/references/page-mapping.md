# 页面跳转映射表

> 跳转入口固定文案不可修改。按功能名称匹配后，使用对应的固定文案。

## 管控Tab页面

| 功能名称 | 功能说明 | 跳转入口固定文案 |
|---------|---------|-------------|
| 管控密码设置 | 设置管控密码，防止孩子通过家长手机修改管控设置 | 去设置管控密码 > |
| 管控密码修改 | 修改已设置的管控密码 | 去修改管控密码 > |
| 管控密码重置 | 忘记密码时自助重置 | 去重置管控密码 > |
| 答案管控（总开关） | 一键关闭/开启答案展示，影响拍照讲题、作业批改、错题本 | 去设置答案管控 > |
| 答案管控（单独设置） | 按应用逐个控制答案是否展示 | 去单独设置查看答案 > |
| 安装软件管控 | 控制是否允许孩子在家教机上安装第三方应用 | 去设置软件安装权限 > |
| 多工具批改管控 | 控制是否允许使用小猿搜题等第三方批改工具 | 去设置批改工具权限 > |
| 应用管控 | 对已安装的应用进行允许/禁止管理 | 去管理应用权限 > |
| 使用时间限制 | 设置每天可用时长和时间段，支持周中/周末分别设 | 去设置使用时间 > |
| 安装和管控记录 | 查看应用安装/卸载记录和管控变更记录 | 去查看管控记录 > |
| 坐姿护眼控制 | 开启护眼/坐姿提醒，距离过近或姿势不当时弹出提醒 | 去设置护眼提醒 > |
| 护眼屏模式 | 切换护眼模式，减少蓝光 | 去设置护眼屏模式 > |
| 屏幕截图 | 每15分钟自动截图，远程查看孩子在做什么 | 去设置屏幕截图 > |
| 摄像头查看 | 实时查看家教机前置摄像头画面 | 去设置摄像头查看 > |
| 异常使用行为监控 | 自动监控23:00-6:00异常使用，默认开启无需设置 | 去查看异常使用记录 > |
