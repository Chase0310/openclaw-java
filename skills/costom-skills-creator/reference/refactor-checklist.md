# Skill 改造清单

## 改造前检查

1. 找出目标 skill 调用的 tool 名和 action。
2. 查 tool schema，确认必填参数、可复用参数、上下文承接参数。
3. 查 tool 返回结构，确认稳定字段是否已经出现在 `output` 中。
4. 如果关键字段只在 `data` 中出现，没有出现在 `output` 中，先记录这个风险。
5. 识别原 skill 是否写死了具体场景、对象名、示例话术或内部对象类型。

## Skill 正文必须补齐的规则

1. 何时触发。
2. 调哪个 tool / action。
3. 哪些参数可以直接复用上下文。
4. 返回结果解读规则。
5. 未命中规则。
6. 错误规则。
7. 回复规则。
8. handoff 规则。

## 返回结果解读规则的最小要求

1. 先看 `status` 与 `found`。
2. 再看 `message`。
3. 再看 `record`、`records`、`facts`。
4. 最后看 `suggestions`、`warnings`、`recommendedNextAction`、`handoff`。

## 通用化检查

1. 删除具体场景名、对象名、场景专属话术和专有领域词。
2. 删除对某个固定示例目录的直接依赖。
3. 把场景特有字段抽成“目标工具的稳定字段”。
4. 把场景特有动作抽成“目标 tool 的 action”。
5. 把示例逻辑改成可复用模式，例如“列表筛查 -> 单项跟进 -> 承接处理”。
